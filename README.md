#

### ℹ️ О программе

Существует популярная библиотека для работы с медиафайлами под названием ffmpeg. Она используется почти везде, где нужно что-либо делать с видео или аудио и часто интегрируется в разные программы.

Работать с ffmpeg можно напрямую — через командную строку или скрипты. Но назвать такую работу комфортной не получится. 

FFToolBox это авторский графический интерфейс для ffmpeg, который значительно упрощает и улучшает взаимодействие с библиотекой.

> Мощный функционал в простом интуитивно понятном интерфейсе.

#

### 🧩 Устройство

Утилита полностью написана на C# — современном языке программирования с тесной интеграцией с Windows.

Никаких сторонних библиотек, скриптов или дополнительных файлов — только чистый код и ffmpeg.exe.

> Скорость обработки ничем искусственно не ограничивается — используется полная мощность ПК.
